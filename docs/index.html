frugal — a thin 9Router setup wizard

A working, free AI setup in one command.

frugal installs and configures a local 9Router, adds the free providers you choose, verifies which models actually answer, and writes a ranked free-best combo with fallback. Then it wires the harness — Pi, OpenCode or Msty. 9Router routes; frugal configures.

Get started View source
Early build. Install with `npm install -g @michaelborck/frugal`; the command is frugal. From-source install is below for development. Built for students on modest laptops: Pi is the default harness, and your existing local Ollama or a shared Ollama server stays untouched.

The ladder

When the subscription is the barrier, there are four places AI can live. Every rung speaks an OpenAI-shaped API, so your tools don't change as you climb — what you learn at the bottom still works at the top:

1 · Local, on your laptop

Ollama + Pi. No keys, no internet, fully private. Runs on modest hardware.

2 · Cloud, direct

One provider, one model, your key. Simple, and the cost stays visible.

3 · Cloud, proxied frugal

9Router holds the keys; free-best fails over a verified chain of free models. This page.

4 · Shared, on campus Puente

A server your institution runs for everyone — the full local stack, no setup. locopuente.org

The whole laptop kit — Node, Ollama, Pi, the skill folders, Msty if you want a GUI — is called mochila (Spanish for backpack): the AI you carry to class. frugal is mochila's cloud rung; Puente is the bridge at the top. Climb as far as you need.

Quickstart

Requires Node.js 22 or newer and a terminal. Install from npm:

npm install -g @michaelborck/frugal
frugal setup

From source, for development:

git clone https://github.com/michael-borck/frugal.git
cd frugal
npm install
npm run build
npm link          # exposes the `frugal` command
frugal setup

frugal setup will:

  • Start 9Router (installing a pinned local copy if needed).
  • Ask for the 9Router dashboard password and log in.
  • Let you add free providers: keys go straight to 9Router, never to frugal.
  • Refresh catalogs, probe a spread of models, and build free-best with Fallback.
  • Write the harness config for Pi (default), OpenCode, or both; Msty gets a paste guide.

Non-interactive (e.g. a class script):

export FRUGAL_ROUTER_PASSWORD='…'
export OPENROUTER_API_KEY='…'
export GROQ_API_KEY='…'
frugal setup --yes --provider openrouter,groq --harness pi --verify

Provider keys can also come from a dotenv-style file: --keys-file ~/.config/frugal/providers.env.

No custom setup needed.

  • Groq

  • NVIDIA NIM
  • Mistral

Custom OpenAI-compatible

frugal registers the provider node, then adds the key.

  • Requesty
  • CrowLLM verify models

Any other OpenAI-compatible endpoint works the same way.

Run frugal guide providers for a thin per-provider guide: signup link, where the key is, the env var, and two or three steps.

Daily check

Free lineups and quotas move. Once a day — or after adding providers:

export FRUGAL_ROUTER_PASSWORD='…'
frugal refresh

It refreshes provider catalogs, probes a spread of models, records reliability, and rewrites free-best with the ones that answered, always with Strategy: Fallback. Add --no-apply to preview, or --limit 5 to probe fewer.

Harnesses

Pi default

Lightest option; good for older laptops.

pi --provider 9router --model free-best

Your Ollama and shared-server providers are preserved.

OpenCode

For machines that can carry it.

Provider router9, model free-best, compaction configured.

Msty

Guided paste into its remote OpenAI-compatible provider screen.

How it works

9Router owns the runtime: provider connections and API keys, routing, fallback, quota tracking, usage charts and the token saver. frugal is deliberately thin: install/start 9Router, help you add providers, verify what actually answers, apply the ranked combo, and wire the harness. A hosted results.json or picks.json is optional if an instructor publishes one; there is no default ranking service to depend on.
